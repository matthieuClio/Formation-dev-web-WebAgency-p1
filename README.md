# WebAgency – Site showcase HTML / CSS

## Project context
This project was completed as part of the **Web Developer** training program by OpenClassrooms.  
The objective was to create a static website based on a provided mockup, while adhering to specific structural and design constraints, and simulating a typical client request for a web agency wishing to present its services.

## Demo
WebAgeency project is available online via GitHub Pages:  
https://matthieuclio.github.io/Formation-dev-web-WebAgency-p1/

## Educational objectives
- Integrate a graphic design using HTML and CSS
- Structure a web page semantically
- Apply good practices for front-end integration
- Implement a responsive website
- Organize a simple front-end project

## Technologies used
- HTML5
- CSS3
- Git / GitHub
- GitHub Pages (deployment)

## Features
- Multi-section showcase website
- Smooth navigation between sections
- Responsive layout (desktop / tablet / mobile)
- Adherence to the provided design template
